Games & simulations.

I’m the developer behind these six projects. My work includes gameplay logic, bot behavior, interfaces, and browser ports of my Python builds.

01 · Game systems

Zero Signal

I wanted to see how much of an FPS I could build with plain JavaScript. It now has nine bots that move and fight on their own, three maps, several weapon classes, grenades, and a complete HUD.

Built
Enemy movement, aiming, spawning, weapons, HUD, and map systems
Stack
JavaScript, Canvas, HTML/CSS

02 · Simulation design

Pandemic Simulator

This started as a Python project about how outbreaks spread. I rebuilt it for the browser so users can choose traits, pick a starting country, and watch infections move through borders, flights, and shipping routes.

Built
Trait system, country model, travel routes, map visualization, and live statistics
